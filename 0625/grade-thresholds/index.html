How to read a grade threshold table

  • Find your row by components. The component numbers are the papers you sat: the first digit is the paper, the second is the variant. Extended candidates take Papers 2, 4 and either 5 or 6; Core candidates take Papers 1, 3 and either 5 or 6.
  • Syllabus thresholds are totals after weighting. Cambridge describes them as the minimum marks for each grade, set from the weighted thresholds of the individual components. The weighted maximum is 200.
  • A* only exists for the whole IGCSE. Cambridge's documents say there is no A* on an individual component.
  • Core rows start at C. Core candidates are eligible for grades C to G, so Cambridge prints a dash for A*, A and B.
  • More than one route to a grade. Where an entry option offers more than one route, Cambridge awards the best grade available from the combination of components the candidate took.

Sitting 0972, the 9–1 version? Cambridge publishes a separate threshold document for 0972, so use that one. Is 0972 the same as 0625? covers the rest.
