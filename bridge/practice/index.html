About this generator

Drills you cannot run out of

Each bridge module ends in a drill, and the drills are fixed sets: you work them once, and the second time through you are partly remembering rather than working. This generator exists for the practice after that. The questions are built from the same eight modules — quantities and base units, standard form, SI prefixes, converting to SI, calculator handling, rearranging equations, significant figures and the seven step method — but the numbers, quantities and contexts are generated each time, so a set is never the set you did yesterday.

The wrong options are not filler. Each one is a mistake that actually turns up on scripts: the right value in the wrong form, the prefix that never got replaced, the conversion factor that was not squared, the whole calculator display copied out. Picking one tells you something, which is why the explanation names the error rather than just restating the right answer.

Not sure which modules you need? The free AS readiness check scores all six skills separately in ten questions. The bridge course itself is where the teaching is.
